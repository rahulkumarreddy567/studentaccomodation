# 🐼 Panda Stays – Student Accommodation Management System (Java)

Panda Stays is a **Java-based student accommodation management system** developed as part of an academic project.  
The application helps students search and view accommodation details while enabling property owners to manage listings efficiently.

This project follows a **Maven-based Java project structure** and demonstrates core concepts of Java application development, database integration, and modular design.

---

## 🎯 Project Objectives

- Provide a centralized platform for student accommodation management
- Allow students to view and explore available housing options
- Maintain accommodation data using a structured database
- Apply Java and Maven best practices in a real-world project

---

## ✨ Key Features

- Student accommodation listings
- Property details with pricing and availability
- Modular Java project structure
- Database integration
- Clean separation of logic and data
- Academic project-oriented design

---

## 🛠️ Technology Stack

- **Language:** Java  
- **Build Tool:** Maven  
- **Database:** SQLite  
- **IDE:** IntelliJ IDEA / Eclipse / VS Code  
- **Version Control:** Git & GitHub

## ⚙️ How to Run the Project

1. Extract the ZIP file.
2. Open the project in **IntelliJ IDEA / Eclipse**.
3. Ensure **Java JDK** is installed.
4. Load the project as a **Maven project**.
5. Allow Maven to download dependencies.
6. Run the main Java class from the IDE.
